What the world actually has

Arena

Void-world pit. Right-click ArenaMaster at the south spawn gate. Gear is vaulted. Waves, named bosses, 1v1 or a bot.

Bosses

Named hosts in the pit. Punch a boss head in any lobby to spar. No rank, no board for a spar.

Crossplay

Same world on Java and Bedrock. Recent Java versions join without a special client.

Proximity voice

Simple Voice Chat on the server. Matching client mod required. Vanilla and Bedrock hear nothing — that is how it works. Install notes.

Killcams

Rolling 60-second clip. PvP deaths auto-clip from victim and killer. Posted after the fight in Media.

Pack

Optional anarchy UI. No popup on join. In game: /pack — low, medium, high, or off.

Quick-chat

Press ; for a sidebar of tactical callouts, or fire a code like ;af. Plays a sound to everyone nearby.

Party

Invite with /party. Middle-click pings a spot on the locator bar. Outsiders see nothing.

Progression

Veteran mark in chat after five hours. Hall of Legends statues. Server Firsts. No paid ranks.
