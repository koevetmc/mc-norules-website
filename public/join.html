How to join

No whitelist. No account application. If you can reach the IP, you are in. GrimAC will ban you if you cheat. That is the only rule.

  1. Java Edition

    Multiplayer → Direct Connection. Paper 26.3. ViaVersion + ViaBackwards accept older and newer Java clients.

    76.176.218.251

  2. Bedrock Edition

    Add server. Address 76.176.218.251, port 19132. Crossplay via Geyser + floodgate. You will not have Simple Voice Chat.

  3. Optional: Simple Voice Chat

    Proximity voice. Server runs voicechat-bukkit 2.6.25. Install the matching client mod for your loader (Fabric, NeoForge, Forge, or Quilt) at the same version. Vanilla Java clients hear nothing. Bedrock hears nothing. That is not a bug.

  4. Optional: anarchy resource pack

    The server offers a 3-tier UI pack. After you join, run /pack low, /pack medium, or /pack high. Medium is the default prompt on join.

  5. Walk out of spawn

    The cobble ring is a WorldGuard pocket: no build, no pvp. The greeting is literal — beyond that line there are no rules. Do not stand in spawn forever expecting a tutorial.
